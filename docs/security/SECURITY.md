# Security Policy

## 1. Supported Versions
| Version | Supported |
|---|---|
| v1.0.x | Yes |
| < v1.0.0 | No |

---

## 2. Reporting a Vulnerability
We take the security and integrity of automated system tweaks seriously. If you discover a security vulnerability (such as unintended registry corruption, arbitrary code execution, or privilege escalation vectors), please report it responsibly:

* **Email:** Open an issue flagged as `[Security Issue]` or contact the maintainer directly.
* **Do NOT** post zero-day exploits in public GitHub issues.

Please provide:
1. Detailed steps to reproduce the issue.
2. The specific PowerShell or Windows version tested.
3. Relevant logs from the `Logs\` folder (ensure sensitive paths or usernames are redacted).

We will investigate and acknowledge valid security reports within 48 hours.
