# 🤝 Руководство по участию в разработке (Contributing)

Мы приветствуем вклад сообщества в развитие **MSI Afterburner & RTSS Suite**!

---

## 🛠️ Требования к коду и оформлению

1. **PowerShell AST & Кодировка:**
   * Все скрипты `.ps1` должны проходить валидацию AST-парсера без синтаксических ошибок:
     ```powershell
     powershell -ExecutionPolicy Bypass -File .\tests\Syntax.Tests.ps1
     ```
   * Кодировка всех `.ps1` файлов строго **UTF-8 с BOM** (заголовок `0xEF 0xBB 0xBF`), переводы строк `CRLF`.
2. **Безопасность конфигураций:**
   * Запрещено применять экстремальный разгон или опасные напряжения по умолчанию.
   * Конфигурации оверлея должны работать на любых разрешениях экрана (1080p, 1440p, 4K) и не вызывать падения Direct3D/Vulkan/OpenGL хуков.
3. **Совместимость с оборудованием:**
   * Код не должен жестко привязываться к одному GPU вендору (`VEN_10DE`). Поддерживайте корректную обработку AMD Radeon (`VEN_1002`) и Intel Arc (`VEN_8086`).
   * Для CPU учитывайте различное количество потоков (от 6 до 32+ ядер).

---

## 🚀 Процесс внесения изменений (Pull Request)

1. Создайте ветку: `git checkout -b feature/ваша-фича`
2. Внесите точечные изменения (минимальное вмешательство).
3. Запустите тесты: `.\tests\Syntax.Tests.ps1`. Все тесты должны иметь статус `[PASS]`.
4. Откройте Pull Request с описанием изменений и приложите лог тестов.
