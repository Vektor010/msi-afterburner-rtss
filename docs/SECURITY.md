# 🛡️ Политика безопасности (Security Policy)

Проект **MSI Afterburner & RTSS Suite** обеспечивает полную прозрачность и безопасность автоматизации мониторинга оборудования.

---

## 🔒 Проверенные источники дистрибутивов

* Все исполняемые файлы MSI Afterburner и RivaTuner Statistics Server загружаются исключительно с официальных зеркал разработчиков (**Guru3D** / **MSI**).
* Проект **не распространяет модифицированные бинарные файлы** и не внедряет сторонний код в память игр.
* Утилита `nvidiaProfileInspector.exe` в папке `tools/` является оригинальной портативной сборкой v2.4.0.4 от Orbmu2k с открытым исходным кодом.

---

## ⚠️ Ложные срабатывания антивирусов (False Positives)

* Драйвер аппаратного доступа MSI Afterburner (`RTCore64.sys`) взаимодействует с регистрами видеокарты на уровне ядра Windows Ring 0.
* Библиотеки RTSS (`RTSSHook64.dll`) осуществляют перехват графических конвейеров (DirectX 9/11/12, Vulkan, OpenGL) для рендеринга экранного меню поверх кадра игры.
* Некоторые эвристические сканеры могут помечать низкоуровневые хуки как нежелательные. Это стандартное поведение для любого игрового оверлея.

---
